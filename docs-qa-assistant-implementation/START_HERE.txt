START HERE — V2 HYBRID RAG
==========================
1. Preserve your existing working version in Git as v1-lexical-retrieval before overwriting it.
2. Extract this ZIP.
3. Copy the ZIP contents into your existing docs-qa-assistant-implementation folder.
4. Use Python 3.11 and follow README.md.
5. Install backend requirements; first install may take several minutes.
6. Add GROQ_API_KEY only to backend/.env.
7. Start FastAPI. First startup downloads all-MiniLM-L6-v2 and builds the persistent ChromaDB index.
8. Start Next.js in a second terminal.
9. Inspect chunk IDs and BM25, semantic and hybrid scores in each answer's retrieval diagnostics.
10. Run pytest -q from backend.

V1 = lexical BM25 baseline.
V2 = BM25 + Sentence Transformers + ChromaDB + RRF hybrid RAG.
